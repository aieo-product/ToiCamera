# ToiCamera docs

ToiCamera is a wrist-worn AI camera: point, shoot, and it explains the world —
on screen and out loud. Source, firmware, Worker and printable case:
[github.com/aieo-product/ToiCamera](https://github.com/aieo-product/ToiCamera).

- **[Worker setup guide](worker-setup.html)** — deploy your own AI relay in ~10 minutes (start here if you cloned the repo)

- **[Y 字ケーブルの作り方](y-cable.html)** — カメラ+GPS 同時使用のための Grove 分岐ハーネス
