# ToiCamera デモ動画 台本(2〜3 分、#8 タスク 1)

方針: 実機体験ファースト。冒頭 15 秒で「撮る→AI が喋る」を見せてから仕組みへ。
撮影は屋外シーン(GPS 地名入り解説)を 1 カット含めると差別化になる。

| # | 時間 | シーン | 映すもの / ナレーション(EN 字幕) |
|---|---|---|---|
| 1 | 0:00-0:15 | フック | 手元アップ: 黄ボタン→即シャッター→AI 解説がアニマルエーズで喋り出す。"A tiny wrist camera that *talks* about what it sees." |
| 2 | 0:15-0:35 | 体験一巡 | ホーム画面(時計・歩数)→黄でファインダー(ライブ 2.5-4fps)→撮影→解説スクロール→黄長押しで音声質問→回答 |
| 3 | 0:35-1:00 | 何ができるか | 被写体 3-4 連発(食べ物・花・看板・ガジェット等)。テンポ良くジャンプカット |
| 4 | 1:00-1:25 | 屋外+GPS | 屋外で撮影→地名入り解説("場所の文脈が解説に入る")。ホームに現在地・最寄り駅表示 |
| 5 | 1:25-1:50 | 仕組み | 図解 1 枚: CamS3 --SoftAP--> StopWatch --WiFi--> Cloudflare Worker --> LLM。「カメラは Stopwatch の AP に直結、ルーター不要」 |
| 6 | 1:50-2:15 | 工夫ポイント | ①0ms シャッター(ファインダーフレーム流用)②オンデバイス アニマルエーズ(TTS 廃止)③light sleep で電池対策 |
| 7 | 2:15-2:35 | ケース+締め | 3D プリントケース装着シーン→腕に着けて街歩き。"Ask the world, one photo at a time." + リポジトリ/Hackster URL |

## 撮影チェックリスト(#4 の 10 被写体エビデンスと兼ねる)

- [ ] 屋内: 食べ物 / ガジェット / 本 / 観葉植物 / ぬいぐるみ
- [ ] 屋外: 花 / 看板 / 建物 / 乗り物 / 風景(GPS fix 状態で)
- [ ] 音声質問のやりとり 1 本(「これは何に使うの?」等、答えが面白くなる質問)
- [ ] スリープ→復帰の動作(電池対策の絵として 3 秒)
- [ ] シリアルログ併録不要(動画は体験のみ、ログは issue エビデンスで担保済み)

## 撮影メモ

- 画面録画不可(実機のみ)なので、スマホ固定+手元が写る俯瞰気味アングル
- アニマルエーズの音をマイクで拾う: 静かな環境で。音量は最大設定済み
- 解説の日本語画面には EN 字幕を後付け(編集時)
- ケース(#5)未完成の場合: シーン 7 を「基板むき出しのプロトタイプ感」で開き直る編集も可
