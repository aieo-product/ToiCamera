# Case — compact-camera-style body

3D-printed enclosure for Bambu Lab X2D. CAD work starts after the MVP is
end-to-end (schedule D8, ~7/30).

Design goals:

- Classic compact-camera silhouette: CamS3 lens front-center, Stopwatch round
  AMOLED as the rear "monitor"
- Yellow button (KEYA) exposed on top-right = shutter; blue button = replay
- Openings: USB-C, speaker, mic; internal Grove power run
- Optional top "hot shoe" mount for Unit GPS v1.1 (Phase 1.5)
- Clearances +0.3mm; two print iterations budgeted
- Deliverables: STEP + 3MF (Bambu Studio project with print profile) + STL
- AMS two-tone (black body + silver grip) as a stretch polish

Fallback if schedule slips: minimal bracket that clamps the two units together
(reuses the CamS3's stock LEGO/clip mount).
